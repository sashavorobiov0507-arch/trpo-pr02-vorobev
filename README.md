# Практическая работа 2

CSS, адаптивная верстка и SCSS

## Что сделано

Сделал адаптивный каталог на HTML и SCSS
На странице есть шапка, панель фильтров, блок с информацией, 18 карточек товаров и подвал
Данные для карточек взял из файла data/catalog.csv
Цвета, радиус и отступ взял из data/theme.json
Панель фильтров сделана только для вида, карточки она не фильтрует, JavaScript я не использовал
Картинки тоже не использовал

## Технологии

- HTML
- CSS (grid, flexbox, медиазапросы)
- SCSS
- Node.js и npm, чтобы компилировать SCSS
- Git

## Что нужно для запуска

Node.js, npm, Git и любой браузер
Проверить что все установлено можно командами node -v и npm -v

## Как запустить

```
git clone ссылка-на-репозиторий
cd trpo-pr02-student
npm install
npm run build
```

После этого открыть файл index.html в браузере

Чтобы SCSS сам пересобирался при сохранении файлов, нужно запустить
```
npm run watch
```
Остановить можно через Ctrl+C

## Как использованы данные

В data/catalog.csv 18 строк и поля id, name, category, price, rating
Я перенес их в index.html руками, одна строка это одна карточка
На карточке показываю название, категорию, цену и рейтинг, id не вывожу

Из data/theme.json я взял значения accent, surface, background, text, radius и space
Они лежат в переменных в начале файла scss/_variables.scss

## Адаптивность

- больше 900px: фильтры слева, каталог справа, карточки в несколько колонок
- меньше 900px: фильтры переходят над каталогом
- меньше 600px: карточки в две колонки, отступы становятся меньше

## Что использовано в SCSS

- переменные для цветов, отступов, радиуса, ширины контейнера и ширин экрана (файл _variables.scss)
- файлы разделены на base, layout и components, их подключает styles.scss через @use
- вложенность (например &__title и &:hover), глубже двух уровней не заходил
- миксины "container", "panel", "tablet" и "mobile" (файл _tools.scss)
- функция "space", она умножает базовый отступ на число, например space(2) это 32px

## Ответы на вопросы

Чем переменная SCSS отличается от CSS переменной

Переменная SCSS (например $accent) работает только пока код компилируется, в готовом CSS она уже заменена на обычное значение и в браузере ее нет
CSS переменная (например --accent) остается в браузере, ее можно поменять в DevTools или через JS и страница сразу обновится
У меня используются переменные SCSS

Зачем нужны partial файлы

Partial это файл с нижним подчеркиванием в начале названия, например _base.scss
Он не компилируется сам по себе, его подключают в главный файл styles.scss
Так стили разбиты на небольшие файлы, в них проще разбираться, а на выходе все равно получается один файл css/styles.css

Где применен mixin

Миксин "panel" делает одинаковый вид белой панели (фон, рамка, скругление, отступ), он используется в .filter, .info и .card
Миксин "container" центрирует содержимое и ограничивает ширину, он используется в .container
Миксины "tablet" и "mobile" нужны для медиазапросов, они используются в _layout.scss, _filter.scss и _card.scss

## Как проверить

1. Выполнить npm install и npm run build
2. Открыть index.html, должны быть видны шапка, фильтры, блок с информацией, 18 карточек и подвал
3. Нажать F12, включить режим адаптивного просмотра и проверить ширины 375, 768 и 1440, горизонтальной прокрутки быть не должно
4. Во вкладке Console не должно быть ошибок
5. Поменять $accent в scss/_variables.scss, снова выполнить npm run build и обновить страницу, цвет у категорий на всех карточках должен поменяться
